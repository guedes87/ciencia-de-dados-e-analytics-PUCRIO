# Pós-Graduação: Ciência de Dados e Analytics | PUC-RIO 📊

Este repositório contém o material desenvolvido durante a minha pós-graduação em **Ciência de Dados e Analytics** na PUC-RIO. Aqui, documento minha jornada de aprendizado, exercícios e, principalmente, os meus **MVPs (Minimum Viable Products)** desenvolvidos ao final de cada sprint.

O objetivo deste portfólio é demonstrar a aplicação prática de técnicas estatísticas, machine learning e análise de dados para resolver problemas reais de negócio.

---

## 🚀 MVPs (Projetos Principais)

Abaixo estão os projetos de conclusão de cada módulo, focados em diferentes pilares da ciência de dados:

### 1. MVP: Análise de Dados e Boas Práticas 📈
* **Descrição:** [Análise exploratória de um dataset de saúde pública utilizando Python e Pandas.]
* **Tecnologias:** Python, Matplotlib, Seaborn, Pandas, NumPy, Missingno e Sklearn.
* **Destaque:** Limpeza de dados (Data Cleaning), padronização e nomralização dos dados, tratamento de missings e extração de insights acionáveis.
* **(https://github.com/guedes87/ciencia-de-dados-e-analytics-PUCRIO/tree/Sprint-Engenharia-de-Dados/an%C3%A1lise%20de%20Dados)**
* **./an%C3%A1lise%20de%20Dado**

### 2. MVP: Machine Learning e Deep Learning 🤖
* **Descrição:** [Ex: Criação de um modelo preditivo para padrões reais de consumo de café, utilizando Random Forest e Regressão Logística.]
* **Tecnologias:** Scikit-Learn, XGBoost, Engenharia de Atributos.
* **Destaque:** Avaliação de métricas (Precisão, Recall e F1-Score).
* **[Link para a pasta do projeto](./an%C3%A1lise%20de%20Dados)**


### 3. MVP: Engenharia de Dados e Cloud ☁️
* **Descrição:** [Ex: Criação de um pipeline de dados dos resultados do Brasileirão Séria A (2013 – 2024), armazenados no Data Lake com a Plataforma Databricks.]
* **Tecnologias:** SQL, PySpark, Docker.
* **Destaque:** Estruturação de bancos de dados e automação de ETL.
